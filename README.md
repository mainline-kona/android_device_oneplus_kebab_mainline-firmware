# Prebuilt Firmware for OnePlus 8T Mainline Linux (kebab_mainline)

This repository contains prebuilt vendor firmware binaries for OnePlus 8T (`kebab_mainline`, SM8250):

- **ath11k/**: Qualcomm QCA6390 hw2.0 Wi-Fi 6 firmware (`amss.bin`, `board-2.bin`, `m3.bin`)
- **qca/**: Qualcomm Bluetooth controller firmware (`htbtfw20.tlv`, `htnv20.bin`)

## Target Path in Android Tree
```
device/oneplus/kebab_mainline-firmware
```
